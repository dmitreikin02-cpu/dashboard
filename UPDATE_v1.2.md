### 4. Автоматическое обновление без Ctrl+Shift+R

**Реализовано TWO-LEVEL обновление:**

#### Уровень 1: Регулярное обновление (каждые 60 сек)
```javascript
setInterval(updateDashboard, 60000);
```

#### Уровень 2: Проверка изменений файла (каждые 5 сек)
```javascript
setInterval(checkFileChanges, 5000);
```

**Как это работает:**

1. **Каждые 5 секунд** дашборд проверяет заголовок `Last-Modified` файла
2. Если файл изменился → **мгновенное обновление**
3. Если файл не изменился → ничего не происходит (экономия ресурсов)
4. **Кеш-бастинг**: каждый запрос добавляет `?t=timestamp` для обхода кеша браузера

**Преимущества:**
- ✅ Обновление в течение 5 секунд после изменения файла
- ✅ Не нужно нажимать Ctrl+Shift+R
- ✅ Минимальная нагрузка (HEAD запрос, не загружает весь файл)
- ✅ Работает в фоновом режиме

### Новые глобальные переменные

```javascript
let lastFileModified = null;  // Отслеживание изменений
let autoRefreshTimer = null;  // Таймер обновления
```

### Функция проверки изменений

```javascript
async function checkFileChanges() {
    const response = await fetch(CONFIG.DATA_PATH + '?t=' + Date.now(), { 
        method: 'HEAD' 
    });
    
    const currentModified = response.headers.get('Last-Modified');
    
    if (lastFileModified && currentModified !== lastFileModified) {
        console.log('📥 Файл изменился, обновляем...');
        await updateDashboard();
    }
}
```

## 💡 Как использовать автообновление

### Сценарий 1: Ручное обновление Excel
1. Открываете `data.xlsx` в Excel
2. Меняете данные
3. **Сохраняете** (Ctrl+S)
4. Через **5 секунд** дашборд автоматически обновится!

### Сценарий 2: Автоматическое обновление Excel
Если у вас скрипт/программа автоматически обновляет `data.xlsx`:
1. Файл сохраняется
2. Через **5 секунд** дашборд подхватит изменения
3. Никаких действий не требуется!

### Сценарий 3: Замена файла
1. Удаляете старый `data.xlsx`
2. Копируете новый `data.xlsx`
3. Через **5 секунд** дашборд обновится

## ⚙️ Настройка частоты проверки

Можно изменить частоту проверки файла в коде:

```javascript
// Текущее значение: 5 секунд
setInterval(checkFileChanges, 5000);

// Изменить на 3 секунды:
setInterval(checkFileChanges, 3000);

// Изменить на 10 секунд:
setInterval(checkFileChanges, 10000);
```

**Рекомендации:**
- 3-5 сек: для часто обновляемых данных
- 5-10 сек: оптимальный баланс
- 10-30 сек: для редко обновляемых данных
