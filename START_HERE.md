
## 🔧 Настройка нормативов:

Откройте `index.html` и найдите:

```javascript
NORMS: {
    receiving: 120,    // Приёмка (штук в день)
    placement: 250,    // Размещение (коробов в день)  
    picking: 300       // Сборка (задач в день)
}
```

Измените значения на ваши и сохраните файл.

## 📈 Цвета на графиках:

- 🔴 **Красный** - меньше нормы (< 100%)
- 🟡 **Желтый** - норма выполнена (100-180%)
- 🟢 **Зеленый** - отлично! (> 180%)

Красная пунктирная линия = норма

## 📁 Ваши данные:

Замените файл `data.xlsx` на ваш с теми же колонками:
- Производственный ресурс
- Дата операций
- Название операции
- Количество операций
- Кол-во, шт
- Кол-во, уп

Дашборд автоматически обновится через 60 секунд.

---

## 🎯 Проверка работоспособности:

### 1. Откройте консоль браузера (F12)
Не должно быть красных ошибок

### 2. Проверьте сеть (Network в F12)
Файл `data.xlsx` должен загружаться успешно (код 200)

### 3. Проверьте данные
- KPI должны показывать числа (не "-")
- Графики должны отображать столбцы
- ТОП-3 должен показывать сотрудников

---

## 🐛 Устранение проблем:

### Графики пустые?
→ Проверьте даты в data.xlsx (должны быть за последние 7 дней)

### Файл не загружается?
→ Используйте `python3 -m http.server`, не открывайте через `file://`

### Неправильные цвета?
→ Проверьте нормативы в CONFIG.NORMS

### Данные не обновляются?
→ Проверьте, что файл data.xlsx действительно обновляется
