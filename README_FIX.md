## ❓ Почему дашборд пустой?

### Причина #1: Старые даты ❌

**Проблема:** Дашборд показывает данные только за последние **30 дней**.

В тестовом файле data.xlsx даты были: `15.01.2024` (старые!)

**Решение:**
```bash
python fix_dates.py
```

Скрипт обновит все даты на сегодняшнюю.

---

### Причина #2: Открыто через file:// ❌

**Проблема:** Вы открыли index.html двойным кликом.

Браузер показывает: `file:///C:/Users/.../index.html`

**Решение:** Используйте локальный сервер!

```bash
python -m http.server 8000
```

Затем откройте: `http://localhost:8000`

---

### Причина #3: Файл data.xlsx не найден ❌

**Проблема:** Файл в другой папке или отсутствует.

**Решение:** 

1. Убедитесь, что файлы в одной папке:
   ```
   C:\Users\daniil.mitreykin\Desktop\Новая папка\
   ├── index.html
   ├── data.xlsx
   ├── fix_dates.py
   └── ...
   ```

2. Или создайте новый файл:
   ```bash
   python create_sample_data.py
   ```

## 🛠️ Проверка через браузер

1. Откройте дашборд
2. Нажмите **F12** (Инструменты разработчика)
3. Вкладка **Console** - ищите красные ошибки
4. Вкладка **Network** - проверьте загрузку data.xlsx

### Типичные ошибки:

| Ошибка | Решение |
|--------|---------|
| `Failed to fetch data.xlsx` | Запустите локальный сервер |
| `CORS error` | Не используйте file://, нужен сервер |
| `404 Not Found` | Файл data.xlsx не найден в папке |
| Данные есть, но графики пустые | Обновите даты (fix_dates.py) |

## 📊 Структура данных

Файл data.xlsx должен содержать:

**Обязательные колонки:**
- ✅ Производственный ресурс
- ✅ Дата операций (в формате DD.MM.YYYY)
- ✅ Название операции
- ✅ Количество операций
- ✅ Кол-во, шт
- ✅ Кол-во, уп

**Операции:**
- `приемка` (или Приемка, ПРИЕМКА)
- `ручные перемещения`
- `привязка к местам`
- `пикинг ЗХ МЕЗОНИН RMIXED`

**Важно:** Регистр не важен, дашборд сам приведет к lowercase.

## 💡 Частые вопросы

### Q: Почему нельзя открыть двойным кликом?

**A:** Браузеры блокируют загрузку локальных файлов (CORS policy). Нужен веб-сервер.

### Q: Как установить Python?

**A:** 
1. Скачайте: https://www.python.org/downloads/
2. Запустите установщик
3. ⚠️ **Обязательно** поставьте галочку: **"Add Python to PATH"**
4. Нажмите "Install Now"

### Q: Python установлен, но команда не работает?

**A:** Попробуйте:
- `python` → если не работает
- `python3` → попробуйте это
- `py` → или это (Windows)

### Q: Данные не обновляются автоматически?

**A:** Дашборд обновляется каждые **60 секунд**. 

Если изменили data.xlsx - подождите минуту или нажмите **Ctrl + Shift + R**.

### Q: Можно изменить период (30 дней)?

**A:** Да! Откройте `index.html`, найдите:

```javascript
DATE_RANGE_DAYS: 30,
```

Измените на нужное значение (например, 7 или 90).
