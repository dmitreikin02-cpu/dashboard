# 🔧 РЕШЕНИЕ: Пустой дашборд

## Проблема
Дашборд не показывает данные - все графики пустые.

## Причина
**Даты в файле `data.xlsx` устарели!**

Дашборд фильтрует данные за последние 30 дней. Если в Excel файле даты старше, данные не отображаются.

---

## ✅ Решение #1: Автоматическое исправление (РЕКОМЕНДУЕТСЯ)

### Шаг 1: Скопируйте файлы
Скопируйте следующие файлы из этой папки в вашу папку:
```
C:\Users\daniil.mitreykin\Desktop\Новая папка
```

Нужные файлы:
- `index.html` (обновленный дашборд)
- `data.xlsx` (с актуальными датами)
- `fix_dates.py` (скрипт исправления)

### Шаг 2: Запустите скрипт исправления

Откройте **PowerShell** или **Командную строку** в папке с файлами и выполните:

```powershell
python fix_dates.py
```

Если не работает, попробуйте:
```powershell
python3 fix_dates.py
```

Скрипт автоматически:
- ✅ Обновит все даты на сегодняшнюю
- ✅ Сохранит файл
- ✅ Покажет статистику

### Шаг 3: Запустите дашборд

```powershell
python -m http.server 8000
```

Или:
```powershell
python3 -m http.server 8000
```

### Шаг 4: Откройте браузер

```
http://localhost:8000
```

Нажмите **Ctrl + Shift + R** для жесткой перезагрузки.

## 🔍 Диагностика проблем

### Проверка #1: Консоль браузера

1. Откройте дашборд
2. Нажмите **F12** (Инструменты разработчика)
3. Перейдите на вкладку **Console**
4. Ищите красные ошибки

**Типичные ошибки:**

❌ **"Failed to fetch data.xlsx"**
→ Запустите локальный сервер (`python -m http.server 8000`)
→ Не открывайте через `file://`

❌ **"CORS error"**
→ Используйте локальный сервер

❌ **Нет ошибок, но данные не показываются**
→ Проблема с датами (см. выше)

### Проверка #2: Network (Сеть)

1. F12 → вкладка **Network**
2. Обновите страницу (Ctrl + Shift + R)
3. Найдите `data.xlsx` в списке
4. Проверьте статус:
   - ✅ **200 OK** - файл загружен
   - ❌ **404 Not Found** - файл не найден
   - ❌ **CORS error** - нужен локальный сервер

### Проверка #3: Даты в файле

Откройте `data.xlsx` и проверьте колонку "Дата операций":
- ✅ Даты должны быть за последние 30 дней
- ❌ Если даты старые - используйте `fix_dates.py`

## 📊 Структура данных

Убедитесь, что в `data.xlsx` есть эти колонки:

**Обязательные:**
- ✅ Производственный ресурс
- ✅ Дата операций
- ✅ Название операции
- ✅ Количество операций
- ✅ Кол-во, шт
- ✅ Кол-во, уп

**Операции должны содержать:**
- `приемка` (или "Приемка", "ПРИЕМКА")
- `ручные перемещения` или `привязка к местам`
- `пикинг ЗХ МЕЗОНИН RMIXED`

**Важно:** Названия операций НЕ чувствительны к регистру!

## 💡 Частые вопросы

### Q: Почему нельзя открыть через file://? 
**A:** Браузеры блокируют загрузку локальных файлов (Excel) из соображений безопасности. Нужен веб-сервер.

### Q: Как установить Python?
**A:** 
1. Скачайте с https://www.python.org/downloads/
2. При установке поставьте галочку "Add Python to PATH"
3. Перезапустите терминал

### Q: Можно ли использовать другой сервер?
**A:** Да! Например:
- **Node.js:** `npx http-server -p 8000`
- **PHP:** `php -S localhost:8000`
- **VS Code:** расширение "Live Server"

### Q: Данные не обновляются автоматически?
**A:** Дашборд обновляется каждые 60 секунд. Если файл `data.xlsx` изменился, данные подтянутся автоматически.
