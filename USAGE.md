# 📖 Руководство по использованию дашборда

## 🎯 Основные сценарии использования

### Сценарий 1: Базовая установка

1. **Скачайте проект:**
   ```bash
   git clone <repository-url>
   cd <project-folder>
   ```

2. **Подготовьте данные:**
   - Поместите ваш файл `data.xlsx` в корневую папку проекта
   - Убедитесь, что структура файла соответствует требованиям

3. **Запустите локальный сервер:**
   ```bash
   python3 -m http.server 8000
   ```

4. **Откройте браузер:**
   ```
   http://localhost:8000
   ```

### Сценарий 2: Настройка нормативов

Отредактируйте файл `index.html`, найдите секцию конфигурации:

```javascript
const CONFIG = {
    // ... другие настройки
    
    NORMS: {
        receiving: 120,    // Измените на вашу норму приёмки
        placement: 250,    // Измените на вашу норму размещения
        picking: 300       // Измените на вашу норму сборки
    }
};
```

### Сценарий 3: Изменение периода анализа

По умолчанию анализируются данные за последние 7 дней. Чтобы изменить:

```javascript
const CONFIG = {
    // ...
    DATE_RANGE_DAYS: 14,  // Измените на нужное количество дней
    // ...
};
```

### Сценарий 4: Настройка частоты обновления

Измените интервал автообновления (по умолчанию 60 секунд):

```javascript
const CONFIG = {
    // ...
    REFRESH_INTERVAL_MS: 30000,  // 30 секунд (значение в миллисекундах)
    // ...
};
```

### Сценарий 5: Изменение цветовой схемы

Настройте цвета для индикации производительности:

```javascript
const CONFIG = {
    // ...
    COLORS: {
        LOW: '#ff0000',    // Цвет для низкой производительности
        MID: '#ffaa00',    // Цвет для средней производительности
        HIGH: '#00ff00'    // Цвет для высокой производительности
    }
};
```

## 📊 Работа с данными

### Формат входных данных

Excel-файл должен содержать следующие обязательные колонки:

| Колонка | Тип | Описание |
|---------|-----|----------|
| Производственный ресурс | Текст | ФИО сотрудника |
| Дата операций | Дата | Дата выполнения операции |
| Название операции | Текст | Название операции (приемка, размещение и т.д.) |
| Количество операций | Число | Количество выполненных операций |
| Кол-во, шт | Число | Количество штук (для приёмки) |
| Кол-во, уп | Число | Количество упаковок (для размещения) |

### Поддерживаемые форматы дат

Дашборд автоматически распознаёт следующие форматы дат:
- `DD.MM.YYYY` (например, 15.01.2024)
- `YYYY-MM-DD` (например, 2024-01-15)
- `DD/MM/YYYY` (например, 15/01/2024)
- Excel serial date (числовой формат)

### Названия операций

Дашборд **не чувствителен к регистру**. Все операции автоматически приводятся к нижнему регистру.

**Категория "Приёмка":**
- приемка
- Приемка
- ПРИЕМКА
- (все варианты распознаются)

**Категория "Размещение":**
- ручные перемещения
- Ручные перемещения
- привязка к местам
- Привязка к местам

**Категория "Сборка":**
- пикинг ЗХ МЕЗОНИН RMIXED
- ПИКИНГ ЗХ МЕЗОНИН RMIXED
- (частичное совпадение также работает)

## 🎨 Интерпретация цветов

### На графиках

Каждый столбец окрашивается в зависимости от процента выполнения нормы:

- 🔴 **Красный** (< 100% нормы)
  - Сотрудник не достиг нормы
  - Требуется внимание менеджера
  
- 🟡 **Жёлтый** (100% - 180% нормы)
  - Норма выполнена
  - Стандартная производительность
  
- 🟢 **Зелёный** (> 180% нормы)
  - Отличный результат
  - Высокая производительность

### На графике отображается:

1. **Столбцы** - фактические показатели сотрудников
2. **Красная пунктирная линия** - норматив (целевое значение)

## 📈 Интерпретация KPI

### KPI-карточки в верхней части

Отображают **общую сумму** по каждой категории за выбранный период:

- **Приёмка**: Общее количество принятых штук
- **Размещение**: Общее количество размещённых коробов
- **Сборка**: Общее количество выполненных задач по сборке

### Заголовки графиков

Содержат динамическую информацию:
- Название категории
- Общая сумма с форматированием

Пример: `Приёмка — всего 370 шт`

## 🏆 ТОП-3 сотрудников

### Критерии отбора

- Сотрудники ранжируются по **общему объёму** выполненных работ
- Учитываются данные за последние `DATE_RANGE_DAYS` дней
- Отображаются только топ-3 по каждой категории

### Цветовая маркировка

- 🥇 **1 место**: Золотой фон
- 🥈 **2 место**: Серебряный фон
- 🥉 **3 место**: Бронзовый фон

## 🔄 Автоматическое обновление

### Как это работает

1. Каждые 60 секунд (по умолчанию) дашборд:
   - Загружает свежий файл `data.xlsx`
   - Обрабатывает данные
   - Обновляет все графики и KPI
   - Обновляет ТОП-3

2. **Время последнего обновления** отображается в заголовке:
   ```
   Обновлено: 14:35:27
   ```

3. **При ошибках**:
   - Выводится красное сообщение с описанием проблемы
   - Предыдущие данные остаются на экране
   - Автоматические попытки обновления продолжаются

### Отключение автообновления

Если нужно отключить автообновление:

```javascript
// Закомментируйте эту строку в функции init():
// setInterval(updateDashboard, CONFIG.REFRESH_INTERVAL_MS);
```

**Firefox:**

## 🛠️ Устранение неполадок

### Проблема: Файл не загружается

**Симптомы:**
- Красное сообщение об ошибке
- KPI показывают "-"

**Решение:**
1. Проверьте, что `data.xlsx` находится в той же папке
2. Используйте локальный веб-сервер (а не открытие через `file://`)
3. Проверьте права доступа к файлу

### Проблема: Данные не отображаются

**Симптомы:**
- Графики пустые
- ТОП-3 не показывается

**Решение:**
1. Откройте консоль браузера (F12)
2. Проверьте ошибки JavaScript
3. Убедитесь, что:
   - Названия колонок в Excel совпадают с требуемыми
   - Даты в данных попадают в диапазон последних 7 дней
   - Названия операций указаны корректно

### Проблема: Неправильные цвета столбцов

**Причина:**
- Нормативы заданы некорректно

**Решение:**
- Проверьте значения в `CONFIG.NORMS`
- Убедитесь, что нормы соответствуют вашим реальным показателям

### Проблема: Автообновление не работает

**Симптомы:**
- Время обновления не меняется
- Данные не обновляются

**Решение:**
1. Проверьте консоль браузера на наличие ошибок
2. Убедитесь, что файл `data.xlsx` действительно обновляется
3. Проверьте значение `REFRESH_INTERVAL_MS`

## 💡 Советы и лучшие практики

### Оптимизация производительности

1. **Размер файла:** Старайтесь держать `data.xlsx` размером < 5 МБ
2. **Период данных:** Используйте разумный `DATE_RANGE_DAYS` (7-14 дней оптимально)
3. **Браузер:** Chrome показывает лучшую производительность для Chart.js

### Резервное копирование

Регулярно создавайте резервные копии `data.xlsx`:

```bash
# Пример скрипта резервного копирования (Linux/macOS)
#!/bin/bash
cp data.xlsx "backups/data_$(date +%Y%m%d_%H%M%S).xlsx"
```

- Алерты при длительном отсутствии обновлений
