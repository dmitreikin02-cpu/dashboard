  Обязательные колонки:
  • Производственный ресурс (ФИО сотрудника)
  • Дата операций (формат: DD.MM.YYYY или YYYY-MM-DD)
  • Название операции (приемка, размещение, сборка)
  • Количество операций
  • Кол-во, шт (для приёмки)
  • Кол-во, уп (для размещения)

  📥 ПРИЁМКА (шт)

     Метрика: "Кол-во, уп"
     Норма: 250 коробов/день

  📋 СБОРКА (задачи)
     Операция: "пикинг ЗХ МЕЗОНИН RMIXED"
     Метрика: "Количество операций"
     Норма: 300 задач/день

╔══════════════════════════════════════════════════════════════════════════╗
║                         КОНФИГУРАЦИЯ                                     ║
╚══════════════════════════════════════════════════════════════════════════╝

  Все настройки в начале index.html:

  const CONFIG = {
      DATA_PATH: 'data.xlsx',          // Путь к Excel
      REFRESH_INTERVAL_MS: 60000,       // Интервал обновления (мс)
      DATE_RANGE_DAYS: 7,               // Период анализа (дни)
      TOP_N: 3,                         // Количество в ТОП-списке
      
      NORMS: {
          receiving: 120,                // Норма приёмки
          placement: 250,                // Норма размещения
          picking: 300                   // Норма сборки
      },
      
      COLORS: {
          LOW: '#ff3b3b',               // Красный
          MID: '#ffcc00',               // Жёлтый
          HIGH: '#00b050'               // Зелёный
      }
  };
