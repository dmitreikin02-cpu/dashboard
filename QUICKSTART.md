# ⚡ Быстрый старт

## За 3 минуты до запуска

### Шаг 1: Установка (30 секунд)
```bash
# Клонируйте или распакуйте проект
cd dashboard-project

# Создайте тестовый файл данных
python3 create_sample_data.py
```

### Шаг 2: Запуск (30 секунд)
```bash
# Запустите локальный веб-сервер
python3 -m http.server 8000
```

### Шаг 3: Открытие (10 секунд)
Откройте в браузере:
```
http://localhost:8000
```

## ✅ Готово!

Вы должны увидеть:
- 3 KPI-карточки вверху
- 3 графика с данными
- ТОП-3 сотрудников под каждым графиком
- Блок нормативов внизу
- "Обновлено: HH:MM:SS" в заголовке

## 🔧 Следующие шаги

### Замените тестовые данные на реальные

1. Подготовьте ваш файл `data.xlsx` со структурой:
   - Производственный ресурс
   - Дата операций
   - Название операции
   - Количество операций
   - Кол-во, шт
   - Кол-во, уп
   - (и другие колонки)

2. Поместите файл в корень проекта (заменив существующий)

3. Обновите страницу - данные загрузятся автоматически

### Настройте нормативы

Откройте `index.html` и найдите:

```javascript
NORMS: {
    receiving: 120,    // Измените на вашу норму
    placement: 250,    // Измените на вашу норму
    picking: 300       // Измените на вашу норму
}
```

Сохраните и обновите страницу.

## 🎯 Типичные проблемы

**Файл не загружается?**
→ Убедитесь, что используете локальный сервер, а не открываете через `file://`

**Данные не отображаются?**
→ Проверьте консоль браузера (F12) и названия колонок в Excel

**Графики пустые?**
→ Убедитесь, что даты в данных за последние 7 дней
