# 📊 Производственный Дашборд

Полностью автономный HTML-дашборд для мониторинга производственных показателей.

## 🎯 Возможности

- ✅ Загрузка данных из Excel-файла (data.xlsx)
- ✅ Автоматическое обновление каждые 60 секунд
- ✅ ETL-обработка данных напрямую в JavaScript
- ✅ Три интерактивных графика (Приёмка, Размещение, Сборка)
- ✅ KPI-карточки с общими показателями
- ✅ ТОП-3 сотрудников по каждой категории
- ✅ Цветовая индикация достижения нормы
- ✅ Визуализация нормативов на графиках
- ✅ Адаптивный дизайн для отображения на телевизоре

## 🚀 Быстрый старт

### 1. Подготовка данных

Поместите файл `data.xlsx` в ту же папку, где находится `index.html`.

Структура Excel-файла должна содержать следующие колонки:
- Производственный ресурс
- Дата операций
- Название операции
- Количество операций
- Среднее время выполнения операции
- Общее время выполнения всех операций
- Время начала работы
- Время окончания работы
- Длительность работы
- Кол-во, шт
- Кол-во, уп
- Кол-во, строк
- Вес
- Объем
- qwe
- qwe2

### 2. Запуск дашборда

Откройте `index.html` в браузере:

```bash
# Простой способ (двойной клик на файл)
# или через командную строку:

# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### 3. Локальный веб-сервер (рекомендуется)

Для корректной работы загрузки Excel-файлов рекомендуется использовать локальный веб-сервер:

**Python:**
```bash
python3 -m http.server 8000
# Откройте http://localhost:8000
```

**Node.js (http-server):**
```bash
npx http-server -p 8000
# Откройте http://localhost:8000
```

**PHP:**
```bash
php -S localhost:8000
# Откройте http://localhost:8000
```

## 📊 Метрики

### Приёмка (шт)
- **Операция:** "приемка"
- **Метрика:** колонка "Кол-во, шт"
- **Норма:** 120 шт/день

### Размещение (короба)
- **Операции:** "ручные перемещения", "привязка к местам"
- **Метрика:** колонка "Кол-во, уп"
- **Норма:** 250 коробов/день

### Сборка (задачи)
- **Операция:** "пикинг ЗХ МЕЗОНИН RMIXED"
- **Метрика:** колонка "Количество операций"
- **Норма:** 300 задач/день

## 🎨 Цветовая индикация

- 🔴 **Красный:** < 100% нормы (требуется внимание)
- 🟡 **Жёлтый:** 100% - 180% нормы (норма достигнута)
- 🟢 **Зелёный:** > 180% нормы (отличный результат)

## ⚙️ Конфигурация

Все настройки находятся в начале JavaScript-кода в файле `index.html`:

```javascript
const CONFIG = {
    DATA_PATH: 'data.xlsx',           // Путь к Excel-файлу
    REFRESH_INTERVAL_MS: 60000,        // Интервал обновления (мс)
    DATE_RANGE_DAYS: 7,                // Период анализа (дни)
    TOP_N: 3,                          // Количество в ТОП-списке
    
    NORMS: {
        receiving: 120,    // Норма приёмки (шт)
        placement: 250,    // Норма размещения (короба)
        picking: 300       // Норма сборки (задачи)
    },
    
    COLORS: {
        LOW: '#ff3b3b',      // Красный (< 100% нормы)
        MID: '#ffcc00',      // Жёлтый (100% - 180% нормы)
        HIGH: '#00b050'      // Зелёный (> 180% нормы)
    }
};
```

## 🔄 Автоматическое обновление

- Дашборд автоматически обновляется каждые **60 секунд**
- Не требуется перезагрузка страницы
- Время последнего обновления отображается в заголовке
- При возникновении ошибок выводится информативное сообщение

## 🔧 Устранение неполадок

### Файл data.xlsx не загружается
- Убедитесь, что файл находится в той же папке, что и index.html
- Используйте локальный веб-сервер (см. раздел "Локальный веб-сервер")
- Проверьте консоль браузера (F12) для получения подробностей об ошибке

### Данные не отображаются
- Проверьте структуру Excel-файла (названия колонок должны совпадать)
- Убедитесь, что даты попадают в диапазон последних 7 дней
- Проверьте правильность названий операций

### Графики не обновляются
- Проверьте, что файл data.xlsx обновляется
- Убедитесь, что интервал обновления корректен
- Откройте консоль браузера для просмотра ошибок
