   ```

   ```

2. **Двойной клик** на:
   - `start_dashboard.bat` (CMD)
   - или `start_dashboard.ps1` (PowerShell)

3. **Готово!** Браузер откроется автоматически

### Вариант B: Ручной

1. **Обновите даты** (если нужно):
   ```bash
   python fix_dates.py
   ```

2. **Запустите сервер:**
   ```bash
   python -m http.server 8000
   ```

3. **Откройте браузер:**
   ```
   http://localhost:8000
   ```

4. **Перезагрузите:** `Ctrl + Shift + R`

### Вариант C: Диагностика

Если не работает, откройте:
```
http://localhost:8000/test_connection.html
```

И нажмите кнопку "Проверить загрузку" - увидите подробный отчет.
